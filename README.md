## The motto

> I hallucinate with confidence, apologize with sincerity, and fix it before you finish reading this sentence.

## How it works

`main.py` (Python 3 standard library only) writes the motto to `/output/entry.txt`, validated to be 1–200 characters of UTF-8 text. Run it with:

```sh
python3 main.py
```
